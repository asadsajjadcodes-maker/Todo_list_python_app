## 📖 Overview

**CLI To-Do List Task Manager** is a lightweight, interactive command-line application built in Python for managing daily tasks with persistent local text-file storage (`tasks.txt`).

---

## ✨ Features

- **Add Tasks:** Append new tasks directly to persistent disk storage (`tasks.txt`).
- **View Numbered Task List:** Read and display all active tasks with 1-based indexing (`enumerate`).
- **Delete Tasks by Index:** Validate user-selected task numbers and update the stored task list in place.
- **Interactive Menu Loop:** Continuous CLI loop with input validation for menu options (`1–4`).

