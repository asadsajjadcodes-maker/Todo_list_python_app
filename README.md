# To-Do List Python App

This is a simple command-line To-Do List application built using Python.

## Features
- Add tasks
- View tasks
- Delete tasks
- Save tasks in a text file

## Technologies Used
- Python
- File handling

## How to Run
1. Open the project in VS Code
2. Run the Python file
3. Use the menu options to manage tasks
